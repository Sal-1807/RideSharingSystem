Database Features Implemented:
  • 15+ Relational Tables with FK constraints
  • Aggregate Functions (COUNT, AVG, SUM, MAX, MIN)
  • Complex JOINs (INNER JOIN across 4+ tables)
  • Subqueries (above-average fare trips)
  • 3 SQL Views (Trip_Details_View, High_Payments, Trip_Ratings)
  • 3 Triggers (status update, wallet deduction, rating validation)
  • 3 Stored Procedures with Cursors
  • UNION set operations
